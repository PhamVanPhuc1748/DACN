## Study and method

The study estimates tail-lesion severity from automatically recorded pictures of slaughter pigs, against trained human observers. It used 13,124 pig pictures; tails were scored on a four-point scale and tail loss was separately recorded. Because tail position varied, the authors first trained a part-detection network to select a rectangular tail crop, then trained a classification network on those crops. The paper says 80% was used for training and 20% for validation.

## Relevance to this project

- **Category:** `related_work`, `architecture_baseline`, `deployment_inspiration` for the detect/crop-then-classify pattern.
- **Applicable:** it supports making ROI selection explicit before classifying a localized sign.
- **Not transferable:** carcass tail close-ups are materially different from live pigs, skin lesions, and whole-pen video; it does not validate a generic pretrained pig detector for this project.
- **Cost:** a crop-based demo is feasible if the input framing is controlled. A detector trained for the project's actual camera view would require labeled ROI data and validation.

The paper identifies picture quality as a source of disagreement. This is evidence for a quality gate and human review path, not a promised performance improvement on this dataset.
