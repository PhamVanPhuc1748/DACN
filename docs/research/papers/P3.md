# P3 — Design and validation of a new machine-learning-based diagnostic tool for the differentiation of dermatoscopic skin cancer images

**Citation:** Amin Tajerian, Mohsen Kazemian, Mohammad Tajerian, Ava Akhavan Malayeri. *PLOS ONE* 18(4) (2023), e0284437. DOI: [10.1371/journal.pone.0284437](https://doi.org/10.1371/journal.pone.0284437). [Article / full text](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0284437). Peer reviewed: yes. **Access:** open access under CC BY. **Status: Verified (full text accessible).**

## Study and method

The authors build a seven-class classifier for dermatoscopic human skin lesions using HAM10000 (10,015 images). The method section describes transfer learning with an EfficientNet family backbone, global average pooling, and a seven-node Softmax output. It reports TensorFlow 2.11, Python, Adam, categorical cross entropy, 19 epochs, batch size 32, and a dynamic learning rate starting at 0.001. **Internal naming inconsistency:** the text calls the backbone EfficientNet-B0 and elsewhere says EfficientNet-B1; this report preserves that inconsistency rather than choosing one.

| Detail | Evidence |
|---|---|
| Image type / labels | Human dermatoscopy, seven HAM10000 diagnostic classes; highly imbalanced. |
| Preprocessing / augmentation | Resize to 240×240 with bilinear interpolation; shifts up to ±20% width/height, shear up to 0.2°, horizontal/vertical flips, nearest-pixel fill (Methods, pp. 3–4). |
| Pretrained weights | Transfer learning is described, but source/checkpoint: `NOT_REPORTED`. The paper freezes the pretrained layers, trains the new head for 15 epochs, then unfreezes the top 50 layers for 4 more epochs. |
| Loss / optimizer / schedule | Categorical cross entropy, Adam; LR starts at 0.001, ReduceLROnPlateau after 3 epochs without validation-loss improvement. Batch size 32, total 19 epochs. |
| Split | Random 8,015 train / 2,000 test (80/20). The paper reports validation metrics during training, but does not describe an independent validation subset or patient-grouped splitting in the reviewed method. |
| Metrics | Overall test accuracy and per-class precision/recall/F1 are reported (Results, Fig. 7 and Table 2). These scores are not comparable to pig data. |
| Code / weights | An app repository is linked by the article, but it is not evidence of released training weights. The paper says its Kaggle data was CC0; confirm the upstream dataset terms before separate reuse. |

## Relevance to this project

- **Category:** `related_work`, `architecture_baseline` (EfficientNet transfer-learning example).
- **Applicable:** report class-wise metrics and inspect errors rather than relying on one aggregate score; provide a reference application pattern.
- **Not transferable:** dermatoscopic human lesions are not RGB pig imagery; its model results cannot rank backbones on this project.
- **Cost:** modest to inspect the evaluation/reporting pattern; reimplementation adds little value before local dataset audit.

Source locations: Methods and split/augmentation (PDF pp. 3–6); dataset and results (pp. 7–10); conclusion (p. 13). Confidence is high for study domain and reported procedure; the paper's abstract/methods call this EfficientNet-B1 while one sentence also calls the baseline B0, so the inconsistency remains explicit.
